# Application Features

## Authentication

The member can:

- Login using mobile number and password
- Request OTP
- Verify OTP
- Logout
- Enable biometric login

## Dashboard

Display:

- Total available balance
- Savings accounts
- Loan outstanding
- Recent transactions
- Quick actions

## Accounts

Member can:

- View accounts
- View account balance
- View account details
- View transaction history

## Transfers

Member can:

- Add beneficiary
- View beneficiaries
- Validate beneficiary
- Transfer money
- View transfer status

## Loans

Member can:

- View loans
- View outstanding amount
- View repayment schedule
- View loan transactions
- Make loan repayment

## Statements

Member can:

- Select account
- Select date range
- Generate statement
- Download statement
